# # IBM Telco Customer Churn Analysis

## Project Overview
This project analyses customer churn in a telecommunications company using Power BI.

The objective is to identify customer segments associated with higher churn and recommend strategies to improve customer retention.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Metrics
- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%

## Analysis Performed
- Customer churn by contract type
- Customer churn by tenure
- Customer churn by senior citizen status
- Monthly charges analysis
- Customer churn by payment method
- Customer churn by internet service

## Key Findings
- Month-to-month contract customers account for the highest churn volume.
- Long-term customers show stronger retention.
- Electronic check users show higher churn.
- Fiber optic customers have a higher churn rate.

## Business Recommendations
- Introduce loyalty programmes for month-to-month customers.
- Improve onboarding for new customers.
- Investigate pricing and service quality for fiber optic subscribers.
- Encourage automatic payment methods.

## Conclusion
The analysis identifies customer segments associated with higher churn and provides actionable recommendations to improve customer retention.
